# 폰찾아 삼만리

목소리로 내 휴대폰을 찾고, 연결한 사람의 휴대폰을 소리나 진동으로 부르는 Android 앱입니다.

이 비공개 저장소는 APK 배포와 설치 안내를 제공합니다. 설치 파일은 **Releases**에서 내려받으세요.

## 지원 환경

- Android 8.0 이상
- 원격 호출: 인터넷 및 Google Play 서비스 필요
- 최초 음성 파일 준비: 인터넷 연결 필요

## 설치

1. Releases에서 `ponsam-v0.1.0.apk`를 휴대폰으로 내려받습니다.
2. 파일을 열고, 필요하면 다운로드에 사용한 앱의 ‘알 수 없는 앱 설치’를 허용합니다.
3. 앱을 설치하거나 기존 버전을 업데이트합니다.

현재 APK는 **디버그 서명된 초기 테스트 버전**입니다. 실제 휴대폰별 음성 인식·절전·원격 울림 동작은 확인이 필요합니다.

## 목소리로 찾기

1. **호출어 → 한국어 음성 파일 준비**를 누르고 완료될 때까지 앱을 열어 둡니다.
2. **음성 대기 켜기**를 누르고 마이크와 알림 권한을 허용합니다.
3. `내폰나와라`라고 말하면 소리로, `내폰조용히나와라`라고 말하면 진동으로 찾습니다.
4. 호출어는 앱에서 변경할 수 있습니다.

음성은 휴대폰 안에서 처리합니다. 울림은 30초 후 자동으로 멈추며 앱이나 알림에서도 중지할 수 있습니다.

## 연결한 휴대폰 찾기

1. 두 휴대폰에 앱을 설치합니다.
2. 양쪽에서 **연결 → 원격 호출 받기**를 켭니다.
3. 한쪽에서 만든 연결 코드를 다른 쪽에 입력합니다.
4. 연결된 기기 카드에서 소리 또는 진동 호출을 누릅니다.

연결 코드는 신뢰하는 사람에게만 공유하세요. 수신 끄기와 연결 해제는 앱에서 할 수 있습니다.

## 알아둘 점

- 전원 꺼짐·앱 강제 종료·인터넷 끊김·절전 제한에 따라 기능이 작동하지 않을 수 있습니다.
- 재부팅 뒤에는 앱을 열어 음성 대기를 다시 켜 주세요.
- 방해 금지 모드에서 알람까지 차단하면 소리나 진동이 제한될 수 있습니다.
- 원격 요청 전송 표시는 대상 휴대폰이 실제로 울렸다는 확인과 다릅니다.
- 누구든 같은 호출어를 말하면 반응할 수 있으며 GPS 위치는 공유하지 않습니다.

## 파일 검증

릴리즈의 `SHA256SUMS.txt`와 APK의 SHA-256을 비교할 수 있습니다.

Windows PowerShell:

```powershell
Get-FileHash .\ponsam-v0.1.0.apk -Algorithm SHA256
```
