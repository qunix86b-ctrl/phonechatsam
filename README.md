# 폰찾아 삼만리

목소리로 내 휴대폰을 찾고, 연결한 사람의 휴대폰을 소리나 진동으로 부르는 Android 앱입니다.

이 공개 저장소는 APK 배포와 설치 안내를 제공합니다. GitHub 로그인 없이 [최신 v0.2.3 APK를 바로 내려받을 수 있습니다](https://github.com/qunix86b-ctrl/phonechatsam/releases/download/v0.2.3/ponsam-v0.2.3.apk).

## 지원 환경

- Android 8.0 이상
- 원격 호출: 인터넷 및 Google Play 서비스 필요
- 최초 음성 파일 준비: 인터넷 연결 필요

## 설치

1. Releases에서 `ponsam-v0.2.3.apk`를 휴대폰으로 내려받습니다.
2. 파일을 열고, 필요하면 다운로드에 사용한 앱의 ‘알 수 없는 앱 설치’를 허용합니다.
3. 앱을 설치하거나 기존 버전을 업데이트합니다.

현재 APK는 **디버그 서명된 초기 테스트 버전**입니다. 실제 휴대폰별 음성 인식·절전·원격 울림 동작은 확인이 필요합니다.

v0.1.0과 같은 서명으로 만들어 기존 앱 위에 업데이트할 수 있습니다. 연결과 설정을 유지하려면 기존 앱을 삭제하지 말고 업데이트하세요.

## v0.2.3 업데이트

- **연결 → 원격 호출은 진동으로만 받기** 옵션을 추가했습니다.
- 이 옵션과 **원격 호출 받기**를 함께 켜면 상대가 소리로 호출해도 내 폰은 진동으로만 받습니다. 상대의 호출 음량도 적용하지 않습니다.
- 진동은 알람 용도로 요청하므로 일반 무음 모드에서도 진동을 시도합니다. 방해 금지·기기 진동 제한·절전 정책에 따라 제한될 수 있습니다.
- 음성 호출과 홈 화면의 직접 테스트는 기존 소리/진동 설정을 사용합니다.
- 옵션을 켤 때 진행 중인 원격 울림은 중지하고, 다음 원격 호출부터 진동만 사용합니다.
- 받는 휴대폰만 업데이트하면 사용할 수 있습니다. 기존 설정을 유지하기 위해 새 옵션의 기본값은 꺼짐입니다.

## 이전 v0.2.2 업데이트

- 제공된 `hwaii.mp3`를 **Hwaii (추가한 음악)** 벨소리로 추가했습니다.
- SMB·8비트 모험 등 기존 6종과 함께 총 **7종** 중 선택할 수 있습니다.
- **설정 → 벨소리와 기본 음량 → Hwaii (추가한 음악)**에서 선택하고 **5초 미리 듣기**로 확인하세요.
- 기존 앱 위에 업데이트할 수 있으며, 기존 벨소리 선택과 연결 정보는 유지됩니다.

## 이전 v0.2.1 업데이트

- 사용자가 제공한 `SMB.mp3`를 **SMB (추가한 음악)** 벨소리로 추가
- 직접 만든 **8비트 모험** 벨소리 추가
- 기존 4종을 포함해 총 6종 중 선택 가능

**설정 → 벨소리와 기본 음량 → SMB (추가한 음악)** 또는 **8비트 모험**을 선택한 뒤 **5초 미리 듣기**로 확인하세요. 선택한 음악은 그 휴대폰에서 소리로 찾을 때 사용됩니다. 기존 선택은 업데이트 후에도 유지되므로 새 소리를 직접 선택해 주세요.

## 기존 v0.2.0 기능

- 연결 코드 생성 창에 **코드 복사**와 **공유** 추가
- **설정 → 벨소리와 기본 음량**에서 벨소리 선택
- 기본 음량 10~100% 자동 저장 및 5초 미리 듣기
- 원격 **소리로 호출**을 누르면 보내는 사람이 그 호출의 음량을 10~100%로 선택
- 내 **원격 호출 받기**를 꺼도 신규 연결과 상대방 호출 가능

원격 호출은 상대가 선택한 벨소리로 울리며 지정 음량은 이번 호출에만 적용됩니다. 이 기능을 사용하려면 **두 휴대폰 모두 v0.2.0으로 업데이트**하세요.

## 목소리로 찾기

1. **호출어 → 한국어 음성 파일 준비**를 누르고 완료될 때까지 앱을 열어 둡니다.
2. **음성 대기 켜기**를 누르고 마이크와 알림 권한을 허용합니다.
3. `내폰나와라`라고 말하면 소리로, `내폰조용히나와라`라고 말하면 진동으로 찾습니다.
4. 호출어는 앱에서 변경할 수 있습니다.

음성은 휴대폰 안에서 처리합니다. 울림은 30초 후 자동으로 멈추며 앱이나 알림에서도 중지할 수 있습니다.

## 연결한 휴대폰 찾기

1. 두 휴대폰에 앱을 설치합니다.
2. 호출을 받을 기기에서 **연결 → 원격 호출 받기**를 켭니다. 보내기만 할 기기는 꺼도 됩니다.
3. 한쪽에서 연결 코드를 만들고 **코드 복사**나 **공유**로 전달해 다른 쪽에 입력합니다. 연결 자체에는 수신을 켤 필요가 없습니다.
4. 연결된 기기 카드에서 **소리로 호출 → 음량 선택 → 호출하기**를 누르거나 진동 호출을 누릅니다.

연결 코드는 신뢰하는 사람에게만 공유하세요. 수신 끄기와 연결 해제는 앱에서 할 수 있습니다.

## 알아둘 점

- 전원 꺼짐·앱 강제 종료·인터넷 끊김·절전 제한에 따라 기능이 작동하지 않을 수 있습니다.
- 재부팅 뒤에는 앱을 열어 음성 대기를 다시 켜 주세요.
- 방해 금지 모드에서 알람까지 차단하면 소리나 진동이 제한될 수 있습니다.
- 원격 요청 전송 표시는 대상 휴대폰이 실제로 울렸다는 확인과 다릅니다.
- 누구든 같은 호출어를 말하면 반응할 수 있으며 GPS 위치는 공유하지 않습니다.
